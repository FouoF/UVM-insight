uvm-insight exporter runs on nodes matching {{ toJson .Values.nodeSelector }}.

Metrics:
  kubectl -n {{ .Release.Namespace }} port-forward ds/{{ include "uvm-insight.fullname" . }} {{ .Values.service.port }}
  curl -s localhost:{{ .Values.service.port }}/metrics | grep ^uvm_

The collector is installed on each node at {{ .Values.hostDir }}/lib.

{{- if .Values.webhook.enabled }}

Automatic injection is on (mutating webhook). A new Pod is patched when:
  - a container requests {{ join ", " .Values.webhook.gpuResources }}, or
  - the Pod has annotation nvidia.com/use-gpuuuid (HAMi), or
  - you set uvm-insight.dynamia.ai/inject=true

Opt out with:
  metadata:
    annotations:
      uvm-insight.dynamia.ai/inject: "false"

Injected fields (mount path {{ .Values.webhook.mountPath | default .Values.hostDir }}):
  CUDA_INJECTION64_PATH, UVMI_SOCKET, hostPath volume,{{- if .Values.webhook.addSysAdmin }} SYS_ADMIN,{{- end }}
  annotation uvm-insight.dynamia.ai/injected=true

Already-running Pods are not changed; recreate them to pick up injection.
{{- else }}

Webhook is disabled. Workloads opt in manually:

  spec:
    containers:
      - name: app
        env:
          - name: CUDA_INJECTION64_PATH
            value: {{ .Values.hostDir }}/lib/libuvminsight.so
          - name: UVMI_SOCKET
            value: {{ .Values.hostDir }}/agent.sock
        securityContext:
          capabilities:
            add: ["SYS_ADMIN"]
        volumeMounts:
          - name: uvm-insight
            mountPath: {{ .Values.hostDir }}
            readOnly: true
    volumes:
      - name: uvm-insight
        hostPath:
          path: {{ .Values.hostDir }}
          type: Directory
{{- end }}

PyTorch images that bundle their own libcupti work as is: the collector uses
whichever libcupti.so.12 the process has loaded.
